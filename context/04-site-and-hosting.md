# 04 · Site and hosting

## Site

- Astro 7.3.8 + MDX + React islands; Remotion clips played in-page with `@remotion/player`.
- Content: `site/src/content/lectures/<id>.mdx` (frontmatter: title, kicker, dek, description, status, ledger,
  `origin`, `footnote`, `contents`, `chapters` with `parts`) + `site/src/content/lectures/<id>/{s0-header,c1-…}.mdx`.
- Each chapter is its own page (`/lectures/<id>/<chapter-slug>/`), plus an overview page.
- Figures: `site/src/figures/<id>/*.tsx` (shared kit); each story lecture has a `so-far.tsx` growing map.
- Clips: `site/src/animations/clips/<clip>/`, posters in `site/public/clips/<clip>/`
  (regenerate with `pipeline/bin/site.sh posters <id>` when clip text changes).
- Components used in MDX: `Section`, `Figure`/`Desk`/`Phone`, `StepThrough`, `PauseAndThink`, `MarginNote`
  (Go deeper), `Cite`, `LectureLink lec="<id>" sec="sX-Y"`.
- Shared template changes made during the story work:
  - Optional frontmatter `origin` and `footnote` (`content.config.ts`, `pages/lectures/[id]/index.astro`, `[chapter].astro`),
    because "From a live whiteboard class" was hard-coded.
  - "Lecture N" labels unpadded (were "Lecture 02"); big index numerals in nav stay padded by design.
- Base path `/vedio-to-blog/` for GitHub Pages is hard-coded in `site/astro.config.mjs` (do not change; Cloudflare
  overrides it with a CLI flag).

## Build and verify

```bash
pipeline/bin/site.sh build lec05      # isolated build of one lecture
pipeline/bin/site.sh links lec05      # zero broken links required
pipeline/bin/site.sh figures lec05    # 360/390/768/1440, light + dark
```

Before every push: full-site build + link check in a **clean git worktree** of the commit
(node_modules symlinked, under `/tmp/vtb-heavy.lock`). Only push if zero broken links. This caught real problems
(old pages still linking to renumbered sections).

## Hosting

1. **GitHub Pages**: https://rmnjaat.github.io/vedio-to-blog/, GitHub Actions on every push to `main`.
2. **Cloudflare Workers (static assets)**: https://system.designnotes.workers.dev
   - Project/Worker name `system`, account subdomain `designnotes`, connected to the GitHub repo, auto-build on push to main.
   - Path `site`; build `npm ci && npx astro build --base /`;
     deploy `npx wrangler deploy --assets=./dist --name=system --compatibility-date=2026-10-01`;
     variable `NODE_VERSION=22`; preview builds off; Cloudflare Access off.
   - Set up without code changes (user's instruction); earlier code edits for it were reverted.
3. Domain discussion: `designnotes.dev` was unregistered (also systemdesignnotebook.dev/.com, whiteboardnotes.dev).
   .dev vs .com discussed; not bought as of this writing.
